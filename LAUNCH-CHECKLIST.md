# Launch checklist

- [ ] Create a Google Calendar appointment schedule named “Consilium Introductory Meeting”.
- [ ] Set duration to 30 minutes, working hours, time zone, booking notice, and buffers.
- [ ] Deploy `google-apps-script/Code.gs` as a web app.
- [ ] Paste the deployed `/exec` URL into `website/config.js`.
- [ ] Paste the Google Calendar booking page URL into `website/config.js`.
- [ ] Test a sample application and confirm it reaches consilium.consultinghq@gmail.com.
- [ ] Test a booking and confirm Google Calendar sends the meeting confirmation.
- [ ] Test on mobile and check the application page carefully.
- [ ] Deploy the `website/` folder to GitHub Pages.
- [ ] Only then share the public website URL.
